## 一、为什么公司财务和高校科研财务处拒绝报销海外英文 PDF Invoice？

无论是通过境外银行卡在 OpenAI / Stripe 后台下载的 `Invoice-XXXX.pdf`，还是在部分境外自助代充网站下载的英文电子收据，在会计入账时都会遇到以下 4 道硬门槛：

| 财务审核卡点 | 海外英文商业 PDF Invoice / Apple 收据 | 国内正规增值税数电发票（普票 / 6% 专票） |
| :--- | :--- | :--- |
| **1. 法定税前扣除效力** | ❌ 无「全国统一发票监制章」，在税法上仅属于境外形式商业账单，不能直接作为企业所得税税前扣除法定发票凭据 | ✅ 国家税务总局监制，具备唯一 **20 位数字电子发票号码**，合规入账零争议 |
| **2. 税务平台真伪查验** | ❌ 无法接入全国增值税发票查验平台，也无法通过企业 OA（每刻、分贝通、金蝶、用友）自动 OCR 验真校验 | ✅ 支持全国增值税发票查验平台实时验真，原生交付 PDF / OFD / XML 标准数电格式 |
| **3. 一般纳税人进项抵扣** | ❌ 0 抵扣；若走对公跨境付汇，企业财务还需额外办理代扣代缴增值税及附加税申报，人工成本远超订阅费本身 | ✅ 批量采购开具 **6% 增值税专用发票**后，一般纳税人可直接认证抵扣 6% 进项税额 |
| **4. 高校/国企资金流水闭环** | ❌ 通常强制要求本人公务外币卡流水 + 银行购汇水单 + 院系领导特批情况说明；找人代付或买礼品卡 100% 退回 | ✅ 人民币对公转账或支付宝实付，金额与发票票面含税价一一对应，完全符合内审要求 |

### 第 1 步：提单前先向财务确认 3 个字段
在付款前，花 1 分钟向公司财务或课题组报销老师确认：
1. **发票种类**：接受「增值税电子普通发票（数电普票）」还是要「6% 增值税专用发票」？
2. **开票抬头信息**：单位全称 + 18 位统一社会信用代码（纳税人识别号）；如开专票可同步备好开户行及账号（数电专票票面已简化，但按公司内部归档习惯填写最稳妥）。
3. **付款路径要求**：允许员工个人支付宝实付报销，还是必须走公司基本户「公对公银行转账」？（注：微信目前不能付款；若需公对公转账，对公收款账户信息不在公开网页直接展示，请在核验唯一官方微信号 `siuserxiaowei` 后在微信内获取）。

## 四、高校与科研院所特别避坑提示

1. **预算科目对齐**：纵向课题经费管理较严，提交开票申请前请先看一眼课题任务书预算表，确认老师名下有充足额度的科目是「技术服务费」「软件服务费」还是「信息网络及软件购置更新费」，事先与专线客服核对合规开票类目，避免因票面品名与课题预算表字眼不符重开。
2. **避免跨年跨结题期长单**：如果课题将在 2 个月后结题审计，建议按月或按实际结题周期采购，确保使用周期落在课题有效执行期内。
3. **退款订单发票规则**：符合未开通退款条件的订单若尚未开票可直接办理退款；如已开具增值税发票且发生合规退订，需按国家税务红字发票冲红规范配合财务完成红冲确认。
